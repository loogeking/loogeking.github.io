# 房客集团登录逆向

> 本文仅可用于学习！！！

网址：https://eip.chanfine.com/j_acegi_security_check

## 一、弄出加密包进行分析（在浏览器中进行即可）

### 1.1、找出加密包

通过输入随意的用户名，密码以及验证码，点击登录触发加密包的生成

![img-1](https://img.loogeking.top/images/房客集团登录逆向/1.png)

显然，`j_username`就是用户名，`j_password`是密码（加密之后的），`j_validation_code`就是验证码；三者就密码进行了加密处理。

### 1.2、确定加密位置

通过搜索关键词`j_password`找到可能的加密位置，再一一分析，确定最有可能的几个打上断点

![img-2](https://img.loogeking.top/images/房客集团登录逆向/2.png)

再次输入触发加密包的生成，而后会断住

![img-3](https://img.loogeking.top/images/房客集团登录逆向/3.png)

这个就是加密函数，只不过这只是一个入口，我们简单分析

- `desEncrypt`就是更深入的加密函数
- `document.forms[0].j_password.value`就是你输入的明文密码

我们进去`desEncrypt`看

```js
function desEncrypt(b, c, a) {
    if (_isMultipartForm(c)) {
        return b
    } else {
        var d = {};
        if (a == null || "sm2" == a.toLowerCase()) {
            d = SECURITYKEY.get("sm2");
            b = SM2Utils.encs(d.SM2PubKey, b)
        } else {
            if ("aes" == a.toLowerCase()) {
                d = SECURITYKEY.get();
                b = CryptoJS.AES.encrypt(b, CryptoJS.enc.Utf8.parse(d.key), {
                    iv: CryptoJS.enc.Utf8.parse(d.iv)
                }).toString()
            } else {
                d = SECURITYKEY.get("des");
                b = CryptoJS.DES.encrypt(b, CryptoJS.enc.Hex.parse(d.key), {
                    iv: CryptoJS.enc.Hex.parse(d.iv)
                })
            }
        }
        return d.security + b
    }
}
```

很明显，这个就是真正的加密函数，有`aes`,`sm2`,`des`等关键字

针对这种多个`if-else`嵌套的，在可能返回加密值的地方打上断点，看看具体是走的哪个分支

![img-4](https://img.loogeking.top/images/房客集团登录逆向/4.png)

### 1.3、加密函数分析

走的是`if (a == null || "sm2" == a.toLowerCase())`这个分支，所以这个代码我们只需要保留这个分支（可能你会觉得换个其他密码形式会是其他分支，这个可以自己尝试，还是这个分支的）

处理好是这样的：

```js
function desEncrypt(b, c, a) {
    var d = {};
    if (a == null || "sm2" == a.toLowerCase()) {
        d = SECURITYKEY.get("sm2");
        b = SM2Utils.encs(d.SM2PubKey, b)
        return d.security + b
    }
}
```

重点看`SECURITYKEY.get`和`SM2Utils.encs`

## 二、扣代码

### 2.1、扣`SECURITYKEY.get`

```js
function(a) {
        var c = SECURITYKEY._getSessionId();
        var b = {};
        if (a == null || a == "aes") {
            if (c.length < 32) {
                c += "abcdefghijklmnopqrstuvwxyz1234567890"
            }
            c = c.toUpperCase();
            b.key = c.substring(0, 16);
            b.iv = c.substring(16, 32);
            b.security = "\u4435\u5320\u4d35"
        } else {
            if (a == "sm2") {
                b.SM2PubKey = window.getSM2PubKey();
                b.security = "\u534d\u3220\u4d45"
            } else {
                if (c.length < 16) {
                    c += "abcdefghijklmnopqrstuvwxyz"
                }
                c = c.toUpperCase();
                b.key = SECURITYKEY.toHexString(c.substring(0, 8));
                b.iv = SECURITYKEY.toHexString(c.substring(8, 16));
                b.security = "\u4445\u5320\u4d45"
            }
        }
        return b
    }
```

依旧是多个`if-else`嵌套，`SECURITYKEY.get("sm2")`传入的是`sm2`定值，直接保留对应的分支

这是改好后的：

```js
function get(a) {
    var b = {};
    b.SM2PubKey = window.getSM2PubKey();
    b.security = "\u534d\u3220\u4d45"
    return b
}
```

### 2.2、扣SM2Utils.encs

```js
SM2Utils.encs = function (key, s, cipherMode) {
    if (s == null || s.length == 0) {
        return "";
    }
    return sm2Encrypt(s, key, cipherMode);
}
```

这个就很棘手了，单靠一步一步扣要很久扣全，观察文件名`sm2.js`；这个名字很有意思，直接全部扣下来改
