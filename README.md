# Loogeking's Blog

Personal tech blog powered by Hexo + Butterfly theme.

**Site**: https://loogeking.bbroot.com

## Tech Stack

- **Generator**: Hexo 8.1.2
- **Theme**: Butterfly 5.5.5
- **Renderer**: markdown-it + mathjax3
- **Deploy**: GitHub Actions - GitHub Pages
- **Search**: hexo-generator-searchdb

## Features

- HarmonyOS glassmorphism design
- Dark/Light theme with auto-dark on post pages
- Responsive layout
- Full SEO (sitemap, RSS, robots.txt)
- Local search
- CI/CD with GitHub Actions

## Quick Start

```bash
npm install
npx hexo server
npx hexo generate
npx hexo new "post title"
```
