# 蓝桥杯 C++ 学习路线总览

> 目标：系统学习蓝桥杯 C++ 算法竞赛，按阶段提升能力。
>
> 定位：以官方公开资料和真题校准学习重点，使用 OI Wiki 等资料补齐基础；本文的优先级属于学习建议，不代表官方考点频率。
>
> 资料核验日期：2026-09-28
>
> 具体组别、题型、分值、评分方式以当年官方章程为准。

---

## 一、这份计划解决什么问题

这份计划只解决三件事：

1. 告诉你蓝桥杯到底需要学什么。
2. 告诉你哪些内容现在不用学，避免在高级算法上浪费时间。
3. 给你一条能持续执行的路线：C++ 基础 → STL → 基础算法 → 搜索 → 数学 → 数据结构 → 贪心 → 动态规划 → 图论 → 字符串 → 真题 → 冲刺。

它不追求“完整 OI 知识体系”，也不把 OI Wiki 的全部内容搬进博客。  
博客只负责路线、顺序、标准和外部链接；具体知识请直接去 OI Wiki、洛谷、牛客等网站学习。

## 二、总路线

```text
C++ 基础
  ↓
STL
  ↓
基础算法：枚举 / 模拟 / 排序 / 前缀和 / 差分 / 二分 / 双指针
  ↓
搜索 + 位运算
  ↓
数学 / 数论
  ↓
数据结构
  ↓
贪心
  ↓
动态规划
  ↓
图论
  ↓
字符串 + 比赛技巧
  ↓
蓝桥杯真题与模拟赛
  ↓
冲刺与复盘
```

顺序不是绝对的，但建议不要跳。  
不能跳过 C++ 基础和 STL 直接学 DP，也不能跳过搜索和递推直接学图论。

## 五、等级定义

| 等级 | 含义 | 处理方式 |
| --- | --- | --- |
| S | 必须掌握 | 不会会明显影响训练，必须刷题验证 |
| A | 强烈建议掌握 | 很有价值，可以在核心基础之后学 |
| B | 应该了解 | 知道用途和基本写法，遇到题能查模板 |
| C | 暂时跳过 | 未来根据真题决定是否学 |
| D | 当前不需要 | 不投入系统学习时间 |

注意：S 不是“要学到 NOI 级”，而是“训练开始前必须打通的地基”。

## 六、学习顺序与依赖

1. 先学 C++ 基础与常用 STL，再进入算法训练。
2. 枚举、模拟、排序、前缀和、差分、二分是搜索、贪心和 DP 的共同基础。
3. DFS/BFS 与位运算可以并行推进；熟悉位运算后再接触状压 DP。
4. gcd、筛法、快速幂与组合计数基础穿插学习，不必等整套数学学完。
5. 栈、队列、堆、并查集、树状数组按所需模型学习；最短路和 MST 分别依赖堆与并查集。
6. DP 先学状态、转移、边界和遍历顺序，再进入线性 DP 与背包；其他模型按题目需要补充。
7. 字符串基础依赖 STL；哈希和 KMP 可在基础算法之后独立学习。
8. 基础算法与搜索完成后即可穿插真题，用结果调整学习优先级。

## 七、刷题策略

### S 级知识点

- 能不看模板写出核心代码。
- 能解释时间复杂度和常见错误。
- 每类至少刷一组基础题和一组变形题。

### A 级知识点

- 能看懂模板、会改模板。
- 知道适用场景和边界条件。
- 每类刷少量典型题即可。

### B 级知识点

- 知道用途和基本写法。
- 遇到题能查模板，不要求默写。

### C / D 级知识点

- C：只保留名称和使用场景印象，不系统学习。
- D：不投入时间。

### 做题记录建议

每道题至少记录：

```text
题目来源 + 题目链接
对应知识点
错误原因
正确思路
复杂度
是否独立做出
下次复习时间
```

## 八、真题与模拟赛什么时候开始

建议不要等到“全部学完”才做真题。

推荐节奏：

1. C++ 基础、STL 和基础算法完成后，选做公开真题中的基础题。
2. 搜索、数学基础和常用数据结构到位后，逐步加入整套真题。
3. DP、图论等模块学习过程中继续穿插真题，不要求等整条路线学完。
4. 冲刺阶段以限时训练、错题复盘和核心模板检查为主；组别与赛制以当年官方资料为准。

真题的作用有两个：

- 检验你是否真的掌握。
- 反向校正知识地图：真题反复出现的 B 可以升级为 A 或 S；从未出现的 C / D 继续保持跳过。

## 九、明确跳过的高级内容

以下内容在“蓝桥杯 C++”目标下，当前不进入主线：

- 网络流、最大流、最小割、费用流
- 2-SAT、最小树形图、斯坦纳树、支配树、弦图、平面图
- 树链剖分、点分治、LCT、树套树、KD 树
- 可持久化线段树、主席树
- 后缀自动机、回文自动机、后缀树、BM
- FFT、NTT、多项式全家桶
- 莫比乌斯反演、杜教筛、Min_25 筛、原根、二次剩余
- 线性规划与单纯形
- 高级计算几何：半平面交、三维几何、旋转卡壳

这些不是“永远不学”，而是当前阶段不优先投入。  
等真题反复出现，或者基础全部完成后，再决定是否升级。
