# 阶段 5：贪心与动态规划

> 阶段目标：能判断贪心是否成立，能独立定义 DP 状态、写转移、处理边界。
>
> 前置阶段：[阶段 4：数学与数据结构](/bluebridge/04-math-ds/)
>
> 本阶段对应知识地图中的 M7 与 M8。

---

## 一、这一阶段要解决什么

阶段 5 是算法建模训练的重要部分；实际优先级需要结合官方公开真题校正。

贪心解决：

- 什么时候可以排序后直接做。
- 区间选点、区间覆盖、调度、合并果子。
- 如何用交换论证和反例检验贪心。

动态规划解决：

- 如何定义状态。
- 如何写转移。
- 如何确定初始化和遍历顺序。
- 先掌握线性 DP 和基础背包；区间、树形、状压等模型在核心内容之后选学。

这一阶段不要求斜率优化、四边形不等式、插头 DP 等高级优化。

## 四、推荐学习顺序

```text
贪心思想与证明
  ↓
区间贪心
  ↓
排序贪心 + 哈夫曼
  ↓
DP 基础：状态 / 转移 / 边界 / 顺序
  ↓
线性 DP
  ↓
01 背包 / 完全背包
  ↓
记忆化搜索
  ↓
区间 DP
  ↓
树形 DP
  ↓
状压 DP
  ↓
DAG / 拓扑 DP
  ↓
前缀和优化
  ↓
数位 / 计数 / 概率 / 单调队列优化（按需选学）
```

原因：

- 先学贪心，再学 DP，有助于理解“为什么不能贪心”。
- DP 基础必须放在所有 DP 模型之前。
- 背包是值得优先练习的基础 DP 模型之一，实际优先级以公开真题为准。
- 树形 DP 依赖树基础。
- 状压 DP 依赖位运算。
- 高级优化放在最后，不要一上来就学。

## 五、掌握标准

### S 级

- 能判断贪心是否成立，并能举出反例。
- 能独立定义 DP 状态。
- 能写出背包的几种形式和空间优化。
- 能分析 DP 的时间、空间复杂度。

### A 级

- 会区间 DP、树形 DP、状压 DP、DAG DP。
- 会前缀和优化。
- 会把记忆化搜索和递推互相转换。

### B 级

- 知道数位 DP、计数 DP、概率期望 DP 的基本模板。
- 知道单调队列优化的适用场景。
- 遇到题能查模板。

## 六、刷题策略

不设本阶段总题量门槛。先完成贪心、线性 DP 和基础背包的代表题；进阶模型按需要补题。

| 类型 | 建议完成标准 |
| --- | --- |
| 贪心 | 完成基础代表题并复盘错题 |
| DP 基础、线性 DP | 能独立定义状态并完成基础题 |
| 01 背包、完全背包 | 完成基础题并掌握遍历顺序 |
| 区间、树形、状压、DAG DP | 按真题与个人进度选做 |

DP 题必须写清三件事：

```text
状态定义是什么
转移方程是什么
初始化和遍历顺序是什么
```

写不出来时，先写暴力搜索，再想能不能记忆化。

## 七、常见坑

1. **贪心不证明**：看起来对不等于真的对，要能举反例或证明。
2. **状态定义不清**：状态含义模糊，转移一定出错。
3. **初始化错误**：DP 数组初始值要区分“不可达”和“0”。
4. **遍历顺序错误**：背包、区间 DP、树形 DP 的顺序都不同。
5. **01 背包倒序**：一维 01 背包容量要倒序。
6. **完全背包正序**：一维完全背包容量要正序。
7. **树形 DP 父子关系**：递归时要传父节点，避免走回父亲。
8. **状压边界**：注意状态范围和 `1LL << k`。
9. **空间爆炸**：先算 DP 数组空间，再决定是否滚动数组。
10. **取模负数**：计数 DP 取模时注意负数。
